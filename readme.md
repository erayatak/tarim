# Tarım Ekipmanları Kullanım Planlama Sistemi

## Projenin Amacı Nedir
Tarım ekipmanları, araçları, cihazları ve malzemelerini hangi çalışanın ya da kullanıcının ne zaman kullandığını takip etmek, kullanım için önceden zaman aralığı beliritlerek ne zaman kime neyin tahsis edildiğini kaydetmek, çakışmaları önlemek ve bir sistem haline getirmek amacıyla geliştirilmektedir.

## Projede Kullanılan Teknolojiler Nelerdir?
Bu projede CSS, HTML, Javascript, PHP, MySQL teknolojilerinden faydalanılmaktadır.
